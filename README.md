# 电工电路仿真调试平台

一个**单文件、免安装**的电工电路仿真器，操作方式类似 eNSP：左侧元件库点选、画布拖拽、端口对端口连线、实时通电仿真与故障诊断。按电工考证实训板建模，可用来自学电路原理、练习接线和排故。

直接用浏览器打开 `index.html` 即可使用，无需 Node、无需构建、无需服务器、无需联网（页面零外部资源）。**网吧/公共电脑**请看 [网吧便携包](#网吧--公共电脑便携包)：一个 HTML 文件即可上传后双击使用。

## 功能

- **完整元件库**：三相/单相电源、4P/2P/1P 断路器与空气开关、闸刀 QS、漏电保护器 RCD、浪涌保护器 SPD、熔断器 FU、交流接触器 KM、热继电器 FR、辅助触点、启动/停止按钮、开关、双联开关、三相电机、白炽灯、日光灯+镇流器、三孔插座、电能表 KWh、零线排 N、地线排 PE、4 段设备接线端子排
- **端口按实物建模**：4P 断路器 8 端子、接触器 8 端子（主触点 6 + 线圈 A1/A2）、热继电器 8 端子（主回路 6 + 常闭 95/96）；端子排每段上下贯通、段与段完全隔离，零排/地排各自独立
- **导线分类与规格**：L / L1 / L2 / L3 / N / PE 六类线色（GB 深色标准，PE 为黄绿双色），规格 1.5 / 2.5 / 4 / 6 mm²；线色错标会触发「布线错误 / 疑似接错」告警
- **eNSP 式连线**：工具栏选择线型后，单击起始端口 → 单击目标端口完成连线，目标自动成为下一段起点，可连续布线；也支持从端子圆点拖拽连线
- **实时仿真**：导线按实测电位着色、悬停端子/导线显示电位、负载亮灭与电机转向实时更新、电能表累计计量
- **故障注入与诊断**：熔断器熔断（可分相缺相）、热继电器跳闸、线圈断路、主触点粘连、断路器分闸、RCD 漏电跳闸、SPD 失效击穿、导线虚接；诊断面板给出现象、原因分析和排查建议，相间短路会定格报警
- **项目管理与作品保存**：内置六个示例项目，可「清空」后自由搭建，保存/载入/删除自定义项目（localStorage）；导出带时间戳的 JSON、导入 JSON、**文本备份/粘贴还原**（网吧禁用下载时也能带走作品）
- **分层排障 L1→L4**：右侧面板按**电源进线层 / 保护配电层 / 控制回路层 / 负载执行层**逐级列出测点读数与状态，标出**首个故障层**；上游故障时下游自动标「受上游影响」，避免把连带失电误判成独立故障。完整方法与三个实操案例见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## 六个示例项目

| 项目 | 内容 |
| --- | --- |
| 项目一 | 电动机单向运转：SB1 启动 → KM 自锁 → 正转，SB3 停止 |
| 项目二 | 电动机正反转：互锁 + 自锁；可注入主触点粘连演示相间短路 |
| 项目三 | 单相计量照明：电能表 → 插座支路 / 日光灯与白炽灯支路 |
| 项目四 | 考场配电板：闸刀 → SPD → RCD → 空开 → 零排/地排分开 → 端子排 → 负载 |
| 项目五 | 两地控制一盏灯：两只双联开关异地翻转 |
| 项目六 | 两台电机顺序启动：KM1 常开辅助触点门控 KM2，FR 常闭串入控制回路 |

项目一和项目四内置了**分层排障练习**：同一个"电机不转 / 灯不亮"的现象，通过不同故障注入分别落到 L1、L2、L3、L4 四层，配合右侧面板逐级定位。

## 操作速查

| 操作 | 说明 |
| --- | --- |
| 单击左侧元件 | 添加到画布 |
| 拖动元件本体 | 移动元件 |
| 拖动空白处 / 滚轮 | 平移画布 / 缩放 |
| 选线型后点两个端口 | 连线（可连续），Esc 退出连线模式 |
| 从端子圆点拖到另一端口 | 连线（另一种方式） |
| 单击导线 | 选中，右侧改类别/规格或删除 |
| Delete / Backspace | 删除选中的元件或导线 |
| 按住按钮元件 | 模拟按下（SB 启动/停止） |
| 双击开关 | 切换合闸 / 掷向 |
| 顶部「保存项目」 | 把当前电路存到浏览器本地 |
| 右侧「🧭 分层排障」 | 查看 L1→L4 各层测点读数、首个故障层与下一步排查建议 |

## 回归测试

```bash
node test.js                # 推荐入口
node tests/regression.js     # 等效
```

**227 项断言，全部通过**（`PASS=227 FAIL=0`）。用例按电路层次分组，而不是堆成一坨脚本：

| 分组 | 覆盖内容 | 断言数 |
| --- | --- | --- |
| L0 冒烟与静态结构 | 六个项目可加载、每根导线两端端子真实存在、8 端子器件/端子排/空开端子数、分层引擎返回四层 | 31 |
| L1 电源与进线层 | 三相/单相进线电位、进线断开定位 L1、无电源元件 | 21 |
| L2 保护与配电层 | QF 分闸、FU 熔断/缺相、FR 动作、主触点粘连短路、RCD 漏电、SPD 击穿、1P/2P 空开支路隔离 | 41 |
| L3 控制回路层 | 自锁/停止、互锁、两地控制、顺序启动联锁、线圈断路 | 33 |
| L4 负载执行层 | 正反转相序、缺相、灯/插座、端子排分段断线、正常操作防误报 | 23 |
| L5 导线分类与规格规范 | 线色/规格标注、火线错标 N 的 danger、N 错标火线的 warn | 11 |
| L6 自定义项目管理 | 保存/载入/删除、属性与规格保留、载入后仍可仿真 | 8 |
| **L7 分层排障场景** | 故障矩阵逐级定位（L1→L4）、blocked 链、排除故障后恢复、短路源头标注、面板渲染 | 43 |
| **L8 便携版作品保存** | 导出 JSON 合法性、时间戳文件名不覆盖、清空后从文本还原、非法文件拒绝、还原后可继续仿真 | 16 |

工程结构：

```
tests/
├── assert.js        # 断言库：10 种断言、分组统计、期望/实际明细、失败清单、退出码 1
├── harness.js       # 夹具：最小 DOM 桩直接加载 index.html 的 <script>，导出仿真 API 与操作 helper
└── regression.js    # L0-L8 分层用例
test.js              # 入口（保持 node test.js 调用方式）
```

断言失败会打印 `expected X, got Y` 并设置进程退出码 `1`，可直接接入 CI。夹具跑的是**产品代码本身**，不存在"测试与实现各写一套模型"导致的假通过。

分层排障的完整方法、三个实操案例、故障矩阵与「如何新增回归用例」见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

## 网吧 / 公共电脑便携包

`index.html` 本身就是完整的离线应用，所以「自己上传、到网吧打开」不需要额外改造，只需要一份可直接分发的包：

```bash
bash build-portable.sh       # 同步两份 HTML 副本 → 跑 227 项回归 → 生成上层目录 circuit-lab-portable.zip
```

产物 `../circuit-lab-portable.zip`（约 84 KB）内 `circuit-lab-portable/` 包含：

| 文件 | 用途 |
| --- | --- |
| `电工电路仿真平台.html` | **本地双击用**；只上传这一个文件也能跑（约 100 KB） |
| `index.html` | 与上面内容完全相同，文件名用于上传到静态空间 / GitHub Pages 根目录自动成为首页 |
| `操作流程.html` / `操作流程.md` | 图文操作流程：四种上传方式、网吧打开步骤、上手流程、作品带回、常见问题 |
| `项目描述.md` | 项目定位、26 种元件、仿真引擎原理、L1→L4 排障模型、六个示例、测试体系与适用边界 |
| `示例作品.json` | 导入格式样例（考场配电板，15 元件 / 27 导线） |

**公共电脑适配**：网吧还原卡会清空本机数据，因此「💾 保存项目」只作临时手段；平台提供 `⤓ 导出`（带时间戳不覆盖）、`📋 文本备份`（复制 JSON 文本，禁用下载时可用）、`⤒ 导入` / `从文本还原` 四条通道，并在首次打开时显示黄色提示条。导出被浏览器拦截会自动打开文本备份窗。详见 `操作流程.html` 第 5 节。

> 用 Chrome / Edge 打开，IE 不支持；Ctrl+0 恢复 100% 缩放可避免点击偏移。

## 发布到 GitHub

仓库里带一个 `publish.sh`，填三个环境变量即可一键推送（会自动创建仓库）：

```bash
export GITHUB_TOKEN=ghp_xxxxxxxxxxxx        # GitHub Personal Access Token，需 repo 权限
export GITHUB_USER=你的GitHub用户名
export GITHUB_REPO=circuit-lab              # 仓库名，不存在则自动创建
bash publish.sh
```

如果目标仓库已经存在，脚本会直接推送到该仓库的 `main` 分支，不会覆盖仓库里的其他文件（仅当远端为空时是快进推送；若远端已有无关历史，需先 `git pull --rebase`）。

也可以走标准 git 流程：

```bash
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

> Token 只从环境变量读取，不会写进仓库文件；推送完成后脚本会把 remote 地址还原为不含 token 的形式。
