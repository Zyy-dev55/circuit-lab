# 电工电路仿真调试平台 · 项目描述

> 版本 v1.0 ｜ 单文件 Web 应用 ｜ 面向电工实训 / 考证考场环境的电路搭建、通电仿真与排障训练平台

---

## 一、项目定位

这是一个**类 eNSP 操作体验的电工电路仿真器**：像网络设备模拟器那样，从元件库拖器件到画布、按端口连线、实时看通断状态，但仿真的对象是低压电工电路——三相电机控制、单相计量照明、考场配电板布线。

它不是原理图绘图工具，而是**"接完线就能通电、能注入故障、能说明问题出在哪一层"的训练台**。最初的输入是一组电工实训图片（电机单向运转与正反转控制原理图、单相电能表与日光灯/插座接线图、实训板与端子排照片），目标是按实物端子粒度把这些电路复现出来，并补上考场板面常见的配电设备。

**核心设计原则**

1. **端子即节点**：每个器件的每个接线端子都是独立可连接节点，不做"设备级抽象端口"，这样才能真实复现 8 端子断路器、8 端子接触器的接线细节。
2. **火 / 零 / 地分开**：零线排与地线排是两个独立器件，导线按 L / N / PE 分类并带规格（mm²），线色与线径由类别和规格决定，错标会被诊断拦截。
3. **能调试、能解释**：不只给"灯亮/不亮"，而是给出故障诊断结论和 L1→L4 分层定位，说明"该从哪一层动手、下一步测哪里"。
4. **零依赖可携带**：所有代码（HTML + CSS + JS）在一个文件内，无 CDN、无字体、无接口请求，`file://` 双击即用，也可上传到任意静态空间变成网址。

## 三、元器件库（26 种，按实物端子建模）

| 分类 | 器件（端子数） |
| --- | --- |
| 电源 | 三相电源 L1/L2/L3/N/PE（5）、单相电源 L/N/PE（3） |

| 控制 | 交流接触器（**8**：主触点 1/3/5·2/4/6 + 线圈 A1/A2）、辅助触点块（4，可关联到指定线圈实现自锁/互锁）、按钮（4，常开+常闭可配）、开关（2）、双联开关（3，单刀双掷） |
| 负载 | 三相异步电动机（4）、白炽灯（2）、日光灯管（2）、镇流器（2）、三孔插座（3，L/N/PE 独立） |
| 计量 | 电能表 KWh（4） |
| 配电 | 端子排 TB（**8**：4 段 × 上下 2 端子，**仅段内贯通、段间完全隔离**，用于设备导线过渡接续）、零线排 N（6 位内部连通）、地线排 PE（6 位内部连通）、空气开关 1P（2）/ 2P（4）、闸刀开关 QS（4）、漏电保护器 RCD（4，30 mA）、浪涌保护器 SPD（3，并接 L/N/PE） |

> 「每个端口八个独立接口」在断路器 4P、交流接触器、热继电器、端子排 TB 上均已落实；零排与地排物理分离，仅在进线处一点相连，下游严禁 N/PE 混接。

## 四、仿真引擎怎么工作

引擎是**基于连通性与相位的逻辑求解器**，不是数值电路仿真：

1. **建图**：每个端子是一个节点；导线、闭合的触点/开关/断路器把两端节点并入同一个并查集（DSU）连通分量。
2. **相位传播**：从电源端子向所在连通分量注入相位标签（L1 / L2 / L3 / N / PE），得到每个节点的电位集合 `rootPh`。
3. **负载判定**：比较负载两端所属的相位集合——两端同相＝无电压不动作；L-N 或 L1-L2 等异相＝得电；三相电机按 U/V/W 三端相序判断正转 / 反转 / 缺相 / 停转。
4. **双稳态迭代**：接触器的线圈是否得电取决于自身辅助触点状态，而辅助触点又取决于线圈状态（自锁/互锁的本质）。因此每次求解**以上一次的线圈状态为初值**反复迭代至收敛（最多 12 轮），否则自锁回路会每次被解成"释放"。
5. **短路检测与定格**：若同一连通分量里出现两个不同相标签（如 L1 与 L3 被直接连通），判定为相间短路。检出后**立即定格该轮结果**，不让后续迭代把它"自动恢复"掉——这样能看到故障瞬间的现象和保护动作，排除故障后需重新启动电路，与真实配电行为一致。
6. **规范检查**：把每根导线声明的类别（L/N/PE…）与实测电位比对，火线错标零/地线报红色危险，零线错标火线报黄色警告。

## 五、分层排障模型（L1→L4）

`layeredDiagnosis()` 沿电流路径分四层逐级判定，返回每层的测点读数、状态、下一步建议，以及**首个故障层 `firstFault`**：

| 层 | 管辖范围 | 典型故障 |
| --- | --- | --- |
| L1 电源与进线 | 各相/零/地进线电位、进线是否接出 | 进线断线、未放置电源 |
| L2 保护与配电 | QF/空开/闸刀/FU/FR/RCD/SPD 状态、短路保护动作 | 分闸、熔断缺相、漏电跳闸、SPD 击穿、相间短路 |
| L3 控制回路 | 按钮、接触器线圈、自锁互锁、辅助触点 | 线圈断路、主触点粘连（短路源头） |
| L4 负载执行 | 电机相序、灯/插座端电压 | 缺相、支路断线、端子排虚接 |

关键设计：上游故障时下游标 `blocked（受上游影响）`，避免把连带失电误判成独立故障；没有接触器的照明电路 L3 标 `skip`；正常操作（例如拨开关把灯关掉）不会被误报为故障。短路会归到 L2（保护动作层），但结论里注明故障源头在 L3 器件。

## 六、六个内置示例项目

| 项目 | 电路 | 训练点 |
| --- | --- | --- |
| 一 · 电动机单向运转 | 电源 → QF → FU → KM 主触点 → FR → M | 启动/停止、自锁、缺相、热保护 |
| 二 · 电动机正反转 | 两台 KM 主触点换相 + 常闭互锁 + 常开自锁 | 互锁必要性、主触点粘连导致相间短路 |

## 七、工程质量

- `tests/assert.js`：正式断言框架，含 `ok / equal / notEqual / true / false / includes / match / deepEqual / count / throws` 等，失败打印 `expected X, got Y` 与明细，分组统计，失败时进程退出码 1（可接 CI）。
- `tests/harness.js`：最小 DOM 桩直接加载 `index.html` 内的 `<script>`，**跑的是产品代码本身**，不存在两套模型的"假通过"。
- `tests/regression.js`：L0–L8 分层回归套件，共 **227 项断言全通过**：

| 分组 | 内容 | 断言数 |
| --- | --- | --- |
| L0 | 冒烟与静态结构（含遍历六个项目校验每根导线两端端子真实存在） | 31 |
| L1–L4 | 电源 / 保护配电 / 控制 / 负载四层电路行为 | 118 |
| L5 | 导线分类与规格规范 | 11 |
| L6 | 自定义项目保存 / 载入 / 删除 | 8 |
| L7 | 分层排障故障矩阵（首个故障层、blocked 链、复位复原、正常操作不误报） | 43 |
| L8 | 便携版作品保存 / 还原（导出 JSON、时间戳文件名、清空后文本还原、非法文件拒绝） | 16 |

运行方式：`node test.js`（等价于 `node tests/regression.js`），无需浏览器、无需安装任何依赖。`TROUBLESHOOTING.md` 提供分层排障的测点/判据表与三个完整案例。

## 九、技术约束与适用边界

**技术约束**

- 单文件、零外部依赖、零构建步骤；Chrome / Edge（或任何 Chromium 内核）打开，IE 不支持；`file://` 与 `http(s)://` 均可运行。
- 不使用较新的 ES 语法（无 `?.` / `??` / `replaceAll` 等），兼容较旧的 Chromium 内核。
- `localStorage` 全部包在 `try/catch` 中且有内存兜底，浏览器禁用存储时不会崩溃；自定义项目存于本机浏览器，公共电脑重启即失效。
- 页面缩放建议 100%，非 100% 时坐标换算可能让点击偏移（用 `Ctrl + 0` 恢复）。

**适用边界（重要）**

这是**教学/考证训练用的逻辑仿真**：判断通断、相序、保护逻辑、故障定位，不做 SPICE 式的电压/电流数值计算、暂态过程、功率因数或热效应分析。它可以用来练接线、理解自锁互锁与保护配合、练分层排障思路，**不能用于实际电气设计、选型校验或安全认证**。
