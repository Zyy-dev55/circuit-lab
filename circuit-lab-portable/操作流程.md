# 电工电路仿真调试平台 · 网吧便携版操作流程

> 一个 HTML 文件就是完整平台：不安装、不联网、不写注册表，上传或拷贝后双击即用。
> 单文件约 100 KB，零外部依赖，Chrome / Edge 打开（**IE 不支持**）。

---

## 1. 怎么带进网吧（自己上传，选一种）

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| A 只传一个文件（最省事） | 把 `电工电路仿真平台.html` 发到微信「文件传输助手」/ QQ / 网盘，到网吧下载后双击 | 没 U 盘、禁用外设、临时用 |
| B U 盘 | 复制整个文件夹（或只那个 HTML），插到网吧机器双击 | 允许读 USB |
| C 网盘 | 上传 `circuit-lab-portable.zip`，网吧登录后下载解压 | 想连说明书一起带走 |
| D 做成网址（推荐长期用） | 把 `index.html` 传到 GitHub Pages / 任意静态空间根目录，得到网址，任何机器输网址即可 | 反复去、多台机器、发给同学 |

**D 方式步骤**：新建公开仓库 → 上传 `index.html`（**文件名必须是 index.html，放根目录**）→ Settings → Pages → Source 选 `main` / `root` → Save → 等 1～2 分钟 → 打开 `https://你的用户名.github.io/仓库名/`。加载一次后即使断网也能继续仿真。

**上传清单**：最小＝只传 `电工电路仿真平台.html`；完整＝整个文件夹 6 个文件；建站＝只传 `index.html`。两个 HTML 内容完全相同，只是名字不同（`index.html` 是给网站自动识别首页用的）。

## 2. 网吧开机后怎么打开

1. 下载 / 解压到桌面或 D 盘（别放「下载」目录，网吧可能定期清空）。
2. 双击 HTML。**默认用 IE 打开会空白或报错** → 右键「打开方式」选 **Chrome / Edge**；360、搜狗要切「极速模式」。
3. `F11` 全屏，`Ctrl + 0` 把缩放恢复到 100%（缩放非 100% 会点击偏移）。
4. 看到左侧元件库、中间画布、顶部六个项目按钮、右侧诊断面板 = 启动成功；顶部黄色提示条点「知道了」。
5. 窗口挤就点 `⛶ 适配视图`。

---

## 3. 五分钟上手（以项目一为例）

1. 点顶部 `项目一`，右侧「📖 电路原理与操作说明」讲这张图的原理。
2. **按住 SB1 启动按钮**（鼠标按下不放）→ KM 吸合 → 电机正转；松开后靠 KM 常开辅助触点**自锁**保持运行。
3. 按住 **SB3 停止** → 控制回路断开 → 电机停转。
4. 选中 **FR 热继电器**，右侧「🧰 元件属性」勾选「动作跳闸」→ 再按启动无效；看「🔍 故障诊断」和「🧭 分层排障 L1→L4」给出的原因和下一步。
5. 取消勾选复位，重按 SB1 → 恢复正常。完成一次「注入故障 → 分层定位 → 排除 → 复测」。

六个示例：项目一 电机单向运转｜二 正反转互锁｜三 单相计量照明｜四 考场配电板｜五 两地控制一盏灯｜六 两台电机顺序启动。

## 4. 自己搭电路（eNSP 式连线）

1. `🗑 清空` 得空白画布；左侧元件库**单击元件**添加，拖元件本体移动。
2. 顶部「连线」选 `🔴 火线` / `🔵 零线` / `🟢 地线`（或自动）+ 规格 1.5/2.5/4/6 mm²。**火零地必须分开选，不能混。**
3. **单击起始端子圆点 → 单击目标端子圆点** 完成连线；目标自动成为下一起点，可连续连；`Esc` 退出。
4. 连线模式下：拖元件本体＝移动元件，拖空白处＝平移画布，滚轮＝缩放。
5. **单击导线**在右侧改类别/规格，`Delete` 或「删除该导线」删除；**双击开关**切换通断；**按住按钮**＝按下。
6. 右侧实时显示仿真状态、故障诊断、分层排障；带电导线按相色显示，悬停端子/导线看电位。

> 线色会被规范检查：火线错标零/地线 → 红色「布线错误，外壳带电，严重触电隐患」；零线错标火线 → 黄色警告。

## 5. 作品怎么带回（最关键）

> ⚠ **网吧有还原卡 / 无盘系统，关机或换机后本机数据全部清空。** `💾 保存项目` 只存在这台机器的浏览器里，**绝不能当唯一备份**。

| 通道 | 操作 | 什么时候用 |
| --- | --- | --- |
| ① `⤓ 导出` | 下载 `circuit-20261112-085530.json` 带时间戳（不覆盖），存网盘/微信/U 盘 | 允许下载时首选 |
| ② `📋 文本备份` | 弹窗点「复制全部」→ 粘贴到微信文件传输助手 / 网盘笔记 / 记事本 | **禁止下载、找不到下载目录时用**；导出被拦截时平台也会自动弹出 |
| ③ `💾 保存项目` | 存本机浏览器，项目栏出现绿色按钮 | 只在同一台机器、本次上机内临时用 |

**下次取回**：`⤒ 导入` 选 `.json` 文件，或 `📋 文本备份` → 粘贴文本 → 「从文本还原」。
文件夹里的 `示例作品.json` 是导入格式样例（考场配电板，15 元件 / 27 导线），可先拿它练一次导入。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 空白 / 报错 / 中文乱码 | 用 Chrome / Edge；确认扩展名是 `.html` 不是 `.html.txt`；别用 IE |
| 「文件来自网络，已被阻止」 | 右键 → 属性 → 勾选「解除锁定」；或换 Chrome 打开 |
| 元件拖不动 | 拖**元件本体**而非端子圆点（那是连线）；或按 `Esc` 退出连线模式 |
| 导线删不掉 | 单击导线选中 → 右侧「删除该导线」或 `Delete`；先在画布空白处点一下移开输入框焦点 |
| 点击位置对不上端子 | `Ctrl + 0` 恢复 100% 缩放，再点 `⛶ 适配视图` |
| 下载被管理软件拦截 | 改用 `📋 文本备份` 复制文本，不依赖下载权限 |
| 重启后作品没了 | 正常，还原卡清空本机数据；只能靠导出或文本备份带回 |
| 上传后打开 404 | 文件名必须 `index.html` 且放在站点/仓库根目录；GitHub Pages 等 1～2 分钟 |
| 网页版能否断网用 | 能。页面无任何 CDN、字体、接口请求 |
