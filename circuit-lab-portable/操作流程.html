⚡ 电工电路仿真调试平台 · 操作流程

网吧 / 公共电脑便携版 —— 一个 HTML 文件就是完整平台，不安装、不联网、不写注册表，上传或拷贝后双击即用。

单文件约 100 KB零外部依赖断网可用Chrome / Edge 打开作品可带回

1怎么把平台带进网吧（自己上传，选一种）

先想清楚一件事：只需要一个 HTML 文件就能跑，其余文件是说明和样例，可传可不传。

方式怎么做适合
A · 只传一个文件
（最省事）		把 电工电路仿真平台.html 发到微信「文件传输助手」/ QQ / 网盘，到网吧下载后双击打开。没 U 盘、网吧禁用外设、临时用一次
B · U 盘把整个文件夹（或只那个 HTML）拷进 U 盘，插到网吧机器上双击。有 U 盘、机器允许读 USB
C · 网盘上传 circuit-lab-portable.zip 到百度网盘 / 阿里云盘 / OneDrive，网吧登录后下载解压。想连说明书一起带走
D · 做成网址
（推荐长期用）		把 index.html 传到 GitHub Pages 或任意静态空间根目录，得到一个网址，网吧任何机器输网址即可，以后再也不用传文件。反复去、多台机器、想发给同学
D 方式具体步骤（GitHub Pages 举例）：
① 新建一个公开仓库（名字随意，如 circuit-lab）→ ② 上传 index.html，文件名必须叫 index.html，且放在仓库根目录 → ③ 仓库 Settings → Pages → Source 选 main / root → Save → ④ 等 1～2 分钟，打开 https://你的用户名.github.io/仓库名/。
加载一次之后即使断网，平台依然能运行（页面不含任何外部资源）。
上传清单：最小＝只传 电工电路仿真平台.html；完整＝整个文件夹 6 个文件；建站＝只传 index.html。两个 HTML 内容完全相同，只是名字不同（index.html 是给网站自动识别首页用的）。

2网吧开机后怎么打开

  1. 把文件下载/解压到桌面或 D 盘（别放在「下载」里，有些网吧会定期清空）。
  2. 双击 HTML 文件。如果默认用 IE 打开导致空白或报错：右键 →「打开方式」→ 选 Chrome 或 Edge；360/搜狗浏览器要切到「极速模式」。IE 不支持，必须用 Chrome / Edge 内核。这是最常见的打不开原因。
  3. 按 F11 全屏、Ctrl + 0 把网页缩放恢复到 100%（缩放不是 100% 会导致点击位置偏移）。
  4. 看到左侧元件库、中间画布、顶部六个项目按钮、右侧诊断面板 → 启动成功。顶部黄色提示条点「知道了」关掉即可。
  5. 窗口太挤就点 ⛶ 适配视图，画布会自动缩放居中。

3五分钟上手：先跑示例（以项目一为例）

  1. 点顶部项目栏的 项目一，右侧「📖 电路原理与操作说明」会讲这张图的原理。
  2. 按住画布上的 SB1 启动按钮（鼠标按下不放）→ KM 接触器吸合 → 电机正转；松开按钮后靠 KM 常开辅助触点自锁继续运行。
  3. 按住 SB3 停止按钮 → 控制回路断开 → KM 释放 → 电机停转。
  4. 选中 FR 热继电器，在右侧「🧰 元件属性」勾选「动作跳闸」→ 再按启动按钮无效；看「🔍 故障诊断」和「🧭 分层排障 L1→L4」给出的原因和下一步建议。
  5. 取消勾选复位，重新按 SB1 → 恢复正常。这就是一次完整的「注入故障 → 分层定位 → 排除 → 复测」。
项目一 / 二电机单向运转、正反转互锁（主触点粘连会报相间短路）
项目三 / 四单相计量照明、考场配电板（闸刀+浪涌+漏电+空开+零排地排）
项目五 / 六两地控制一盏灯、两台电机顺序启动

4自己搭电路（eNSP 式连线）

  1. 点 🗑 清空 得到空白画布；在左侧元件库单击分类里的元件即可添加到画布，拖住元件本体可移动。
  2. 顶部「连线」工具选线型：🔴 火线 🔵 零线 🟢 地线（或「自动」），再选规格 1.5 / 2.5 / 4 / 6 mm²。火零地必须分开选，不能混。
  3. 单击起始端子圆点 → 单击目标端子圆点完成连线；目标端口自动成为下一次的起点，可以连续连。按 Esc 退出连线模式。
  4. 连线模式下：拖元件本体＝移动元件，拖空白处＝平移画布，滚轮＝缩放，三者互不干扰。
  5. 单击导线可在右侧改类别/规格，或按 Delete / 点「删除该导线」；双击开关切换通断；按住按钮＝按下。
  6. 右侧实时给出仿真状态、故障诊断、分层排障结论；带电导线按相色显示，悬停端子或导线可看电位。
线色规范会被检查：把火线错标成零线/地线，诊断面板会报「布线错误，外壳带电，严重触电隐患」；零线错标火线会给黄色警告。选错线型连出来的线一眼就能看出来。

5作品怎么带回（网吧最关键的一节）

⚠ 网吧普遍有还原卡 / 无盘系统，关机或换机后本机数据全部清空。顶部「💾 保存项目」只存在这台机器的浏览器里，绝不能当唯一备份。离开前一定做完下面任一步。
通道操作什么时候用
① 导出文件
⤓ 导出		下载得到 circuit-20261112-085530.json 这类带时间戳的文件（不会互相覆盖），存到网盘 / 微信 / U 盘。网吧允许下载时，首选
② 文本备份
📋 文本备份		弹窗里点「复制全部」→ 粘贴到微信文件传输助手、网盘笔记或记事本保存。文本就是标准电路 JSON。网吧禁止下载 / 找不到下载目录时，用这个；导出被浏览器拦截时平台也会自动弹出这个窗
③ 保存项目
💾 保存项目		存到本机浏览器，项目栏出现绿色按钮，点一下就载入。只在同一台机器、本次上机内临时用

下次怎么取回

  • 点 ⤒ 导入 选之前下载的 .json 文件；或
  • 点 📋 文本备份 → 把保存的文本粘贴回文本框 → 点「从文本还原」。
  • 文件夹里的 示例作品.json 是导入格式的样例（考场配电板，15 个元件 / 27 根导线），可以先拿它练一次导入。

6常见问题

现象处理
打开空白 / 一堆报错 / 中文乱码用 Chrome 或 Edge 打开；确认扩展名是 .html 而不是 .html.txt；别用 IE。
提示「文件来自网络，已被阻止」右键文件 → 属性 → 勾选「解除锁定」→ 确定；或直接换 Chrome 打开。
元件拖不动要拖在元件本体上，不要拖端子圆点（那是连线）；若还不行按 Esc 退出连线模式再拖。
导线删不掉单击导线选中 → 右侧「删除该导线」或按 Delete。选中前先在画布空白处点一下，避免焦点留在输入框。
点击位置对不上端子Ctrl + 0 恢复 100% 缩放，再点 ⛶ 适配视图。
下载被网吧管理软件拦截改用 📋 文本备份 复制文本保存，不依赖下载权限。
重启后作品/保存的项目没了正常，还原卡会清空本机数据。只能靠导出文件或文本备份带回，见第 5 节。
上传到网站后打开是 404文件名必须是 index.html，并放在站点 / 仓库根目录；GitHub Pages 需等 1～2 分钟生效。
网页版能不能断网用能。页面没有任何 CDN、字体或接口请求，加载完成后断网照常仿真。
